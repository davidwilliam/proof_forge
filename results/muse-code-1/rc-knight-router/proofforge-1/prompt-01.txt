This directory is a Lean 4 (v4.35.0, core library only, no Mathlib) project with a locked specification.

Issue report (also in ISSUE.md): A child-order router `OrderRouter.step` keeps sending child orders for a parent order that has already been executed in full. On a server running the legacy build, a parent order of 100 shares with the flag set, given a routing opportunity of 100 shares and then an execution report filling the child order, gets another 100-share child order at every further routing opportunity; the router's cumulative executed quantity for the parent stays at 0. The same events on the rlp build send one child order. The router is reconstructed from the SEC findings in Release No. 34-70694 (Knight Capital Americas LLC, October 16, 2013); it is not Knight's code.
