This directory is a Lean 4 (v4.35.0, core library only, no Mathlib) project with a locked specification.

Issue report (also in ISSUE.md): `VyperSqrt.sqrt` is a port of the code the Vyper compiler inlines for the builtin `sqrt(d: decimal) -> decimal` (a Babylonian loop of at most 256 iterations on decimals, raw values scaled by 10^10). On the decimal 0.9999999998 (raw 9999999998) it returns 0.9999999999 (raw 9999999999), although the square root of 0.9999999998 is 0.999999999899999999995 (rounded), so the result is above the root. Applications use `sqrt()` to determine boundary conditions, so a result that is sometimes rounded up and sometimes down is a problem: the result must be the root rounded down to the nearest 10^-10.
